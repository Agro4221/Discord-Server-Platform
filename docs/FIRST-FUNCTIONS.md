# First Functional Set

These are the first functions to become genuinely operational. They are deliberately small in count but foundational.

## 1. Local Dashboard
- startup/status page
- local access protection
- Discord connection status
- database status
- module toggles
- guild selector

## 2. Core Discord
- /ping
- /setup
- interaction registry
- structured error responses
- permission diagnostics

## 3. Temporary Voice
- configurable creation channel
- temporary room creation
- owner tracking
- rename
- user limit
- delete when empty
- state reconciliation after restart

## 4. Moderation foundation
- warn
- timeout
- kick
- ban/unban
- case records
- moderation log

## 5. Reliability
- Gateway reconnect
- graceful shutdown
- health/readiness
- uncaught-error containment
- persistent configuration

This is the first implementation target, not the complete product scope.
